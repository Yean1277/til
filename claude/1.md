# Google AI Studio 高级用法 · 2026 整理

## 一、定位先搞清楚

AI Studio 已经不只是 prompt playground 了——它覆盖从原型到生产的全链路 [Ai](https://www.ai.cc/blogs/google-ai-studio-guide/) 。最佳实践是：用 AI Studio 做探索和原型，工作流成熟后再迁移到 Vertex AI 走治理、合规、监控 [Android Experto](https://androidexperto.com/google-ai-studio-features-costs-limitations-2026/) 。

## 二、Build Mode（Vibe Coding）

核心入口，从一句话到可部署应用。

支持用自然语言提示构建全栈 Web 应用和 Kotlin + Jetpack Compose 的原生 Android 应用 [Google AI](https://ai.google.dev/gemini-api/docs/aistudio-build-mode) 。

**关键技巧：**
- 用 System Instructions 给 AI 设定持续生效的「人设」（Vibe Check），后续编辑都遵循同一风格 [Google Codelabs](https://codelabs.developers.google.com/vibe-code-with-gemini-in-aistudio)
- **AI Chips** — 不只是装饰，每个 chip 把特定能力注入你的应用（Maps、图像生成等可叠加） [0xminds](https://0xminds.com/blog/guides/google-ai-studio-vibe-coding-tutorial)
- **Annotation Mode** — 视觉变化用文字难描述时，直接在预览上画出你的意图 [Google Codelabs](https://codelabs.developers.google.com/vibe-code-with-gemini-in-aistudio)
- 一键导出 GitHub 仓库，或直接部署到 Cloud Run 拿到公网 URL [LBSocial](https://www.lbsocial.net/post/gemini-3-google-ai-studio-tutorial)

## 三、Grounding 三件套

**Google Search Grounding** — 实时世界知识，减少幻觉。

**Google Maps Grounding** — 连接 Gemini 推理能力和超过 2.5 亿个 places 数据，做地理感知 AI [Google](https://blog.google/innovation-and-ai/technology/developers-tools/grounding-google-maps-gemini-api/) 。返回 context token 可以渲染成交互式 widget，自带照片、评论等 [Google](https://blog.google/innovation-and-ai/technology/developers-tools/grounding-google-maps-gemini-api/) 。

**Maps Grounding Lite（MCP）** — 通过标准化 MCP 集成快速接 LLM；支持 Maps Demo Key，不用信用卡就能开始；2026 起还在私测扩展路由能力，能给出实时旅行时间和考虑路况的方向 [Google Maps Platform](https://mapsplatform.google.com/resources/blog/powering-the-next-era-of-agentic-experiences-announcing-new-grounding-capabilities/) 。

## 四、工具组合（2026 新能力）

现在可以在单次 Gemini API 调用里把内置工具（Google Search、Google Maps）和自定义 function calling 组合起来，跨工具调用和多轮对话循环上下文，做更复杂的 agentic 推理 [Google](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tooling-updates/) 。

实战例子（来自官方）：
```
1. 用 Google Search 查上周加州最大地震
2. 然后打开灯（function call）
```
一次请求同时挂 `googleSearch` 和 `functionDeclarations`。

## 五、Live API（实时多模态）

Live API 支持 function calling 和 Google Search grounding 作为 session 配置的一部分。注意：和 generateContent 不同，Live API 不自动处理工具响应，客户端要用 session.send_tool_response 手动回传 FunctionResponse [Google AI](https://ai.google.dev/gemini-api/docs/live-api/tools) 。

原生音频 + 工具使用 + 跨模态连续记忆，企业级稳定性已 GA，支持多区域部署 [Google Cloud](https://cloud.google.com/blog/topics/developers-practitioners/how-to-use-gemini-live-api-native-audio-in-vertex-ai) 。

适合做：语音助手、实时屏幕共享分析、对话型 agent。

## 六、模型选择与思考预算

复杂 prompt 把 thinking_level 设成 "high"；Gemini 3 Pro 在 SWE-bench Verified 拿 76.2%，WebDev Arena 1487 Elo [Aibuilders](https://aibuilders.academy/vibe-coding-with-gemini-3/) 。

2026 当前主力：
- **Gemini 3 Pro** — 复杂推理、长上下文（1M token）、agentic
- **Gemini 3.5 Flash** — 2026 年 5 月 19 日发布，已成 Gemini app 和 AI Mode 默认模型；速度比同档前沿模型快 4 倍，输出 289 tokens/秒，价格低于 Gemini 3.1 Pro [Ai](https://www.ai.cc/blogs/google-io-2026/)

## 七、结构化输出

JSON Schema 直接锁定输出结构，做数据提取、表单填写、API 桥接稳定可靠。Build Mode 教程里 YouTube Summarizer 例子专门有「Crafting Structured JSON Output Prompts」环节 [Udemy](https://www.udemy.com/course/build-genai-apps-google-ai-studio-vibe-coding-masterclass/) 。

## 八、媒体生成集成

Imagen 4 在 Gemini API 和 AI Studio 已 GA，文字渲染显著改善，Imagen 4 和 Imagen 4 Ultra 支持最高 2K 分辨率 [Android Sage](https://www.androidsage.com/2026/03/19/google-ai-studios-biggest-update-yet/) 。Veo 视频模型、Nano Banana 图像编辑都能直接在 workspace 里组合用——一个 prompt 同时调用多模态生成。

注意：Veo 3 和 Nano Banana 是高算力模型，通常需要绑定 Google Cloud 计费账户。常看 Usage 标签避免超限 [LBSocial](https://www.lbsocial.net/post/gemini-3-google-ai-studio-tutorial) 。

## 九、部署链路

AI Studio 一键部署到 Cloud Run，支持 Firebase [Ai](https://www.ai.cc/blogs/google-io-2026/) 。完整路径：

```
Build Mode 描述 → Gemini 生成代码 → Annotation 微调 →
导出 GitHub / 一键部署 Cloud Run → 公网 URL
```

## 十、易踩的坑

AI 生成的代码经常能跑但不是生产级——一定要进 code view 检查 geminiService.ts 和组件文件再上线 [0xminds](https://0xminds.com/blog/guides/google-ai-studio-vibe-coding-tutorial) 。

免费层数据会用来训练模型，敏感场景注意隐私 [Wikipedia](https://en.wikipedia.org/wiki/Google_AI_Studio) 。需要治理就用 Vertex AI。
